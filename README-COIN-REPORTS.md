# ติดตั้งระบบรายงานเหรียญบน XAMPP

ระบบนี้เพิ่มตาราง `coin_transactions` สำหรับเก็บบัญชีรายการเหรียญแบบตรวจสอบย้อนหลังได้ โดยจะบันทึกอัตโนมัติเมื่อแอดมินอนุมัติการโอนเงิน และเมื่อผู้อ่านซื้อตอนนิยาย

## วิธีปรับฐานข้อมูล

ตั้งค่า MySQL ใน `.env` ของ Laravel ให้ตรงกับ XAMPP แล้วสั่งในโฟลเดอร์โปรเจกต์:

```powershell
php artisan migrate
```

ไม่ต้องแก้ตารางเดิมด้วย phpMyAdmin ด้วยตนเอง เพราะ migration `2026_08_29_000000_create_coin_transactions_table.php` จะเพิ่มตารางและดัชนีให้เอง หากฐานข้อมูลมีตารางเดิมจากโปรเจกต์อยู่แล้ว

ตารางเดิมที่ใช้ร่วมกัน:

- `coin_topups`: หลักฐานและยอดเงินที่โอนซื้อเหรียญ
- `chapter_purchases`: ผู้ซื้อ ตอนที่ซื้อ และราคาที่ใช้จริง ณ เวลาซื้อ
- `coin_transactions`: รายการเหรียญเข้า/ออก พร้อมยอดคงเหลือหลังทำรายการ

## หน้าระบบที่เพิ่ม

- `/admin/coin-reports` — แอดมินดูรายการโอนเงิน รายการซื้อตอน และสรุปรายสัปดาห์
- `/author/earnings` — ผู้แต่งดูยอดเหรียญรวมรายวันและแยกตามนิยายของตนเอง โดยไม่เห็นข้อมูลผู้อ่าน

ตาราง `coin_transactions` เป็นสมุดบัญชี ไม่ควรแก้หรือลบรายการย้อนหลัง หากจำเป็นต้องคืนเหรียญ ควรเพิ่มประเภทรายการคืนเงินใน migration/โค้ดภายหลังแทนการแก้ยอดเดิม
